# Dolgorae AI

회전기계의 알람 확인부터 트렌드 분석, 근거 기반 진단, 정비 보고서 초안 생성까지 연결하는 AI Agent 프로젝트입니다.

## 저장소

| 저장소 | 역할 |
| --- | --- |
| [frontend](https://github.com/dolgorae-ai/frontend) | 채팅, 알람 목록, 센서 차트, 보고서 편집 화면 |
| [backend](https://github.com/dolgorae-ai/backend) | 운영 데이터 API, 인증·인가, 보고서 저장 |
| [ai-agent](https://github.com/dolgorae-ai/ai-agent) | LangGraph·RAG 기반 진단 및 보고서 생성 |
| [ml-service](https://github.com/dolgorae-ai/ml-service) | 이상탐지, 트렌드 분석, 주기적 탐지 |
| [infra](https://github.com/dolgorae-ai/infra) | 공통 개발 환경 및 팀 문서 |
